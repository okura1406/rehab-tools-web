# contrib — 共同編集者のファイル置き場

評価ツールを一緒に作っている方が、**HTMLファイルと仕様書を置く場所**です。

ここに置いたファイルは、公開サイトの一覧にはまだ出ません。
内容を確認したうえで、管理者が公開サイト（トップページの一覧）へ組み込みます。

---

## 置き場所は「この contrib フォルダの中」でお願いします

`contrib` の中に置いていただくと、管理者が次の3つを整えてから公開サイトに載せます。

- **オフラインで動く**ようにする（電波の届かない場所でも採点が止まりません）
- **ツール一覧に載せる**（ST評価ツールのページから開けるようにします）
- 公開用のファイル名に変換する（例：`嚥下評価ツール.html` → `swallow.html`）

リポジトリのトップ（`contrib` の外）に置くと、**この3つが入らないまま公開されます。**
ファイル自体は開けますが、電波が無い場所では開けず、一覧にも出てきません。

### 見分け方

アップロードの前に、画面の上のほうの表示を見てください。

```
rehab-tools-web / contrib   ← この中に置いてください
rehab-tools-web             ← ここはトップ。上の3つが入りません
```

### いちばん確実な方法

次のリンクをブックマークして、そこから
「ドラッグ＆ドロップ → Commit changes」してください。必ず `contrib` の中に入ります。

<https://github.com/okura1406/rehab-tools-web/upload/main/contrib>

置き場所が違っていても管理者のほうで移せますので、心配は要りません。

---

## ファイルの置き方（Gitの知識は不要です）

ブラウザだけで完結します。

1. **このページ（`contrib`）** の上部にある **「Add file」** → **「Upload files」** を押す
2. HTMLファイルや仕様書（.md）を、点線の枠の中へ**ドラッグ＆ドロップ**する
3. 下の **「Commit changes」** の緑ボタンを押す

これだけで共有完了です。更新版を上げるときも、同じファイル名で同じ操作をしてください。
（古い版は履歴として残るので、消えることはありません）

### ファイル名について

日本語のファイル名のままで構いません。公開サイトに載せるときに、管理者が英数字の名前へ変換します。

例：`嚥下評価ツール.html` → 公開時 `swallow.html`

## 置いてよいもの / いけないもの

| | 内容 |
|---|---|
| **置いてよい** | 評価ツールのHTMLファイル、仕様書（.md / .txt）、画面の説明用スクリーンショット |
| **置いてはいけない** | **患者氏名・ID・生年月日などの個人情報**、職員の氏名が入ったファイル、勤務表 |

> **重要**
> このリポジトリは **Public（公開）** です。URLを知っていれば誰でも閲覧できます。
> 検索エンジンには登録されない設定ですが、アクセス制限ではありません。
> 個人情報を含むファイルは、テスト用であっても絶対に置かないでください。

## 公開サイトに載るまでの流れ

```
あなた                    管理者
  │                        │
  ├─ contrib/ にアップロード →│
  │                        ├─ 内容を確認
  │                        ├─ 公開用の調整
  │                        │   ・ファイル名を英数字に
  │                        │   ・オフライン対応の組み込み
  │                        │   ・トップページの一覧に追加
  │                        │
  │←──── 公開完了の連絡 ─────┤
```

公開用の調整は管理者側で行うので、**あなたはツールの中身だけを考えていただければ大丈夫です。**

---

## ツールを作るときのお願い

公開サイトはスマートフォンからの利用を前提にしています。以下に沿っていると、そのまま組み込めます。

- **1つのHTMLファイルで完結させる**（外部のライブラリを読み込まない）
  - 電波が届かない場所でも動くようにするため、これが最も重要です
- 入力データは端末内（`localStorage`）に保存し、**外部へ送信しない**
- スマートフォンの画面幅（375px程度）で横スクロールが出ないようにする
- ボタンは指で押しやすい大きさにする

既存のツール（`../battery.html`、`../pain.html`、`../updrs.html`）が参考になります。
分からない点は管理者に相談してください。
