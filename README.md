# リハ評価ツール（ウェブ公開版）

リハビリテーション部門で使用する評価尺度ツールを、スマートフォンから利用できるように公開したものです。

## 収録ツール

| ファイル | 内容 |
|---|---|
| `index.html` | ツール一覧（トップページ） |
| `battery.html` | 評価尺度ツール（SPPB ほか） |
| `pain.html` | 疼痛評価ツール |
| `design-r.html` | DESIGN-R®2020 褥瘡状態評価 |

## 特徴

- **オフライン対応**：一度開けば端末内に保存され、電波が届かない場所でも起動・採点できます（Service Worker による）。
- **外部通信なし**：採点ロジックは各HTMLファイル内で完結しており、外部のライブラリを読み込みません。
- **データを送信しない**：入力内容は端末内（localStorage）の下書き保存のみで、サーバーには一切送信されません。
- **検索避け**：`robots.txt` と `noindex` により検索エンジンには登録されません（アクセス制限ではありません）。

## ツールを更新したときの注意

HTMLを修正して反映する場合は、**`sw.js` の `CACHE_VERSION` の数字を必ず1つ増やしてください。**

```js
var CACHE_VERSION = 'v1';   // → 'v2' に変更する
```

この数字を変えないと、すでにツールを開いたことがある端末に古い版が残り続けます。

新しいツールを追加した場合は、`sw.js` の `PRECACHE_URLS` と `index.html` の一覧にも追記してください。
