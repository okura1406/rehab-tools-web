## 特徴

- **オフライン対応**：一度開けば端末内に保存され、電波が届かない場所でも起動・採点できます（Service Worker による）。
- **外部通信なし**：採点ロジックは各HTMLファイル内で完結しており、外部のライブラリを読み込みません。
- **データを送信しない**：入力内容は端末内（localStorage）の下書き保存のみで、サーバーには一切送信されません。
- **検索避け**：`robots.txt` と `noindex` により検索エンジンには登録されません（アクセス制限ではありません）。

## ツールを更新するとき

**このフォルダのHTMLを直接編集しないでください。** 正本は `評価バッテリー　QRコード/` にあります。

正本を修正したあと、`評価バッテリー　QRコード/公開に反映.bat` を実行すると、
コピー・公開用タグの再付与・`CACHE_VERSION` の更新・push までが自動で行われます。

手作業で反映する場合は、**`sw.js` の `CACHE_VERSION` を必ず1つ増やしてください。**

```js
var CACHE_VERSION = 'v1';   // → 'v2' に変更する
```

この数字を変えないと、すでにツールを開いたことがある端末に古い版が残り続けます。

新しいツールを追加した場合は、`sw.js` の `PRECACHE_URLS`、一覧ページ（`index.html`
または `st.html`）、`_publish_tools.py` の `TOOLS` の3か所に追記してください。

`contrib/` に置かれたツールについては、`評価バッテリー　QRコード/新着をとりこむ.bat` が
この3か所への追記までを自動で行います（取り込みの前に、中身を目で確認する手順が入ります）。
